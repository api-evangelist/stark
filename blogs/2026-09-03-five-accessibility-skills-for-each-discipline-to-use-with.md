Stark's accessibility skills are now available for any AI coding agent that support them, which covers Claude, Cursor, Codex, VS Code, and GitHub Copilot. Each skill teaches your agent how to handle accessibility work in the discipline it's already operating in — design files, front-end code, native mobile, back-end responses, or program-level compliance — so what you get back matches the surface you're working on instead of a generic WCAG summary.
